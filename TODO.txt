Cool-Toast — Pendientes
=======================

Objetivo
--------
Crear Cool-Toast: un port de goey-toast (https://goey-toast.vercel.app/) para Svelte,
con nuestro propio toque, para usarlo en nuestros proyectos en Svelte.

Paquete de referencia (registro de npm, revisado el 2026-10-27)
---------------------------------------------------------------
- Nombre: goey-toast 0.5.0
- Descripción: componente de toast "gooey" que se deforma, construido sobre Sonner con animaciones de Framer Motion
- Licencia: MIT (el port debe conservar el aviso de copyright y la licencia originales)
- Repositorio: https://github.com/anl331/goey-toast
- Dependencias peer: react >=18, react-dom >=18, framer-motion >=10
- Dependencias: sonner ^2.0.7

Tareas
------
[ ] 1. Descargar el código de referencia: npm install goey-toast
[ ] 2. Estudiar el código de goey-toast: API pública, opciones, efecto gooey y animaciones
[ ] 3. Decidir con qué reemplazar en Svelte las piezas que solo funcionan en React:
        - sonner (motor de toasts)
        - framer-motion (animaciones)
[ ] 4. Definir la API pública de Cool-Toast y "nuestro toque" (SDD con lead-worker)
[ ] 5. Crear la página de demostración con el skill /svelte-creator (SvelteKit + Svelte)
[ ] 6. Implementar Cool-Toast en Svelte 5 con Strict TDD (worker-qa + worker-web)

Restricciones
-------------
- Sin API, sin trabajos en segundo plano, sin base de datos y sin app: solo la librería y su página de demostración.
- La página de demostración se crea con el skill /svelte-creator.
